# AI-Powered-Medical-Knowledge-Assistant-Using-RAG
RAG-based medical Q&amp;A assistant that answers clinical questions from the 4,114-page Merck Manual. Built with LLaMA-2 13B (GGUF), LangChain, ChromaDB and BGE embeddings, it compares prompt-only vs retrieval-grounded answers and scores groundedness and relevance with an LLM judge. Python, Google Colab. Educational prototype.
